# USE THIS SYSTEM

After installation + bootstrap, stop pasting the 16 rule files into prompts.

Normal prompts should be short.

Examples:

Bug:
`Investigue e corrija este erro: <erro>. Escopo mínimo. Valide antes de concluir.`

Feature:
`Implemente <feature>. Siga a arquitetura do projeto, faça a menor implementação completa e valide.`

Visual:
`Refine visualmente <tela>. Foque em estética, hierarquia, cards, botões, spacing, responsividade e estados. Não altere regra de negócio.`

Review:
`Revise as alterações atuais e corrija somente problemas materiais encontrados.`

Ship:
`Faça o pre-ship das alterações atuais. Só considere pronto se as verificações relevantes passarem.`

The descriptions in each SKILL.md let Codex select skills implicitly. You can also explicitly invoke a skill from Codex when desired.
