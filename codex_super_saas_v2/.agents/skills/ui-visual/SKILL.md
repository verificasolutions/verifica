# UI visual
1. Read `agent-system/standards/ui-ux.md`.
2. Inspect current components/tokens and reuse them.
3. Understand screen purpose/actions without loading unrelated domains.
4. Improve hierarchy, spacing, typography, surfaces, controls and responsive behavior.
5. Handle applicable loading/empty/error/success/disabled states.
6. Preserve accessibility and keyboard behavior.
7. Do not change business logic unless explicitly requested.
8. Use available browser/preview tooling to inspect result when possible.
9. Verify type/lint/build scope as appropriate.
10. Report visual change and verification only.
