# Implement feature
1. Read project goal/architecture and affected module context only.
2. Inspect nearest existing implementation pattern.
3. Define concise done conditions.
4. For multi-step work, make a short execution plan; for simple work, start.
5. Implement the smallest complete vertical slice.
6. Preserve tenant/security/permissions/events/state rules where applicable.
7. Add/update tests following existing project patterns.
8. Run relevant checks.
9. Review final diff.
10. Report only what changed, verification and blockers.
